Why a DHL label PDF needs cropping

4×6 inch is the standard shipping label size for DHL — the same standard used by UPS, FedEx and USPS — and it is the size thermal label printers are built around. The catch is the file: when a DHL label is downloaded as a PDF, it frequently arrives on an A4 or Letter page, with the label occupying only part of the sheet.

Send that page straight to a 4×6 thermal printer and the print driver has to shrink or clip it to fit. The result is a label that prints too small, loses its edges, or produces a barcode the courier's scanner can't read. Cropping first — so the PDF page is the label, nothing more — removes the mismatch entirely, and the printed label comes out at exactly the size DHL expects.

How to crop a DHL label to 4×6

  1. Save the DHL label as a PDF. Download the label file for your shipment and keep it as-is — whether the page is A4 or Letter, the tool handles both.
  2. Drop the PDF into the cropper above. Everything runs in your browser; the file is never uploaded to a server.
  3. Check the blue crop box. Auto-detect finds the label area on the page. Make sure the barcode and every address line are inside the box, and drag a corner dot to fine-tune it.
  4. Choose the output size and download. Use 4×6 in, or 100×150 mm if that's the size your printer driver lists. For multi-page PDFs, each page is cropped individually — or copy one page's crop to all pages in a click.
  5. Print at 100% scale with the paper size set to 4×6. Turn off "Fit to page" — the cropped PDF already matches your label stock exactly.

DHL label questions

What size is a DHL shipping label?

4×6 inch (101.6×152.4 mm) is the standard shipping label size for DHL, and the size 4×6 thermal printers use. Some printer drivers list the near-identical 100×150 mm size instead — this tool can export either, so pick the one your driver names.

My DHL PDF contains labels on several pages. Can I crop them all at once?

Yes. The tool works with multi-page PDFs: every page gets its own auto-detected crop box, you can adjust pages individually, and one download exports all of them as 4×6 pages.

Will the DHL barcode still scan after cropping?

Yes — the cropped label is scaled to fit inside the 4×6 page without stretching, so the barcode keeps its exact proportions. Print at exactly 100% scale; shrinking to fit is what breaks scannability.

Do I need to install software or create an account?

No. The cropper runs 100% in your browser — no install, no sign-up, no watermark, and your label PDF is never uploaded to a server. See the FAQ for more on how it works.
